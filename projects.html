Research projects

What makes E. coli biofilms hard to get through?

PhD project, Centre for BioImaging Sciences, NUS

Uropathogenic E. coli build biofilms held together by curli fibres and cellulose. I combine SPIM-FCS, light-sheet microscopy, AFM, digital holographic microscopy and Brillouin spectroscopy to measure how molecules and antimicrobial peptides move through these biofilms, and how that relates to the biofilm's mechanics.

See the related publications

DNA nanoparticles as drug carriers in biofilms

Collaboration with UiT The Arctic University of Norway

Measuring how three types of DNA-based nanoparticles diffuse through and stay inside Pseudomonas aeruginosa biofilms, to guide which drugs to pack into which carrier.

Software and tools

FCS Plotter

Web tool, rebuilt and extended

An open-access web tool for plotting and comparing fluorescence correlation spectroscopy data in the browser, no installation needed. I rebuilt it and added normalisation options, axis scaling and binning.

Code on GitHub

Brillouin spectra analysis

Python pipeline (Jupyter notebook)

Extracts Brillouin frequency shifts from VIPA-based spectrometer data, which tell you about a sample's stiffness without touching it. It calibrates the frequency axis with a polynomial fit to the Rayleigh peaks, then fits Lorentzian peaks to get the shifts.
